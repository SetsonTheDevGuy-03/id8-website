# ID8 Technologies AI Website Build Pack

This folder contains the Markdown files to feed into your AI design and coding tools.

## Recommended order

1. `01_MASTER_STRATEGY.md`
   - Read this first.
   - Use it as the business and website source of truth.

2. `02_DESIGN_SYSTEM.md`
   - Use this as DESIGN.md.
   - Feed into Stitch, Antigravity, Cursor, and Kiro.

3. `03_GOOGLE_STITCH_PROMPTS.md`
   - Use this for visual exploration.
   - Generate homepage, hero, services, research/marketing, case study, contact, and mobile layouts.

4. `04_ANTIGRAVITY_BUILD_PROMPTS.md`
   - Use this for implementation.
   - Build in sections, not all at once.

5. `05_CLAUDE_PROMPTS.md`
   - Use for copy, service data, case studies, code review, debugging, and prompt improvement.

6. `06_CURSOR_KIRO_WORKFLOW.md`
   - Use for structured coding, task breakdown, and project rules.

7. `07_WEBSITE_CONTENT_COPY.md`
   - Use for website text and section copy.

8. `08_BUILD_QA_DEPLOYMENT_CHECKLIST.md`
   - Use before launch.

## Best workflow

Stitch → Claude → Antigravity → Cursor/Kiro → Claude Review → Deploy

### Stitch
Use for design exploration.

### Claude
Use for copy, structured data, content refinement, code review.

### Antigravity
Use to build and verify the website.

### Cursor
Use for targeted code edits and debugging.

### Kiro
Use for specs and task-based implementation.

## Important rule
Do not ask any AI tool to “build the whole website” in one go.

Instead:
- Build the design system
- Build the layout
- Build one section at a time
- Verify
- Polish
- Deploy
