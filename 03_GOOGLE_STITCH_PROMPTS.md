# Google Stitch Master Prompt Pack for ID8 Technologies

## Purpose
Use this file to generate website UI concepts in Google Stitch.

Stitch should be used for:
- Visual exploration
- Homepage layout options
- Hero section design
- Services section design
- Case study layouts
- Mobile layout ideas
- Component inspiration

Do not use Stitch as the final production builder. Use it to create the visual direction, then rebuild properly in Next.js/Tailwind with Antigravity, Cursor, Claude, or Kiro.

---

# 9. Stitch Output Instructions

After Stitch generates designs:
1. Screenshot the best versions.
2. Export/paste to Figma if available.
3. Save visual direction notes.
4. Create or update DESIGN.md.
5. Do not paste Stitch code directly into production without review.
6. Use Antigravity/Cursor to rebuild cleanly in Next.js/Tailwind.
